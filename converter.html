📌 How to use


BUCO emails: Save the "Order Created" email as a .eml file → drag it here → get your Pastel CSV.


Cashbuild CSVs: Export from the supplier portal as CSV → drop it here → done.


BUCO batch CSVs: Same format — the tool detects which client the order is for automatically.


Prices are looked up from the Flash Harry price list. The output matches the format used by Pastel for direct import.
